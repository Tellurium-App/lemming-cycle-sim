# レミングはなぜ4年ごとに大発生して消えるのか — 論文のモデルで確かめる

グリーンランド北東部のクビワレミングが約4年ごとに大発生して減る仕組みを説明した
Gilg, Hanski & Sittler (2003) のモデル（レミング＋オコジョ＋シロフクロウ・ホッキョクギツネ・トウゾクカモメ）を
自前で書き直し、4つの検証で確かめた記録です。
YouTube チャンネル「AIのなかみ」の動画で使ったコードと、検証の基準・結果をそのまま置いています。

出典: Gilg, O., Hanski, I., & Sittler, B. (2003). Cyclic dynamics in a simple vertebrate predator-prey community.
*Science*, 302(5646), 866–868.

式と数値は、Barraquand らの公開コード（github.com/fbarraquand/lemmingCycles_ODEmodels の
`predation/GilgEtAl2003/original_model`・GPL-3.0）から読み取りました。
数値は事実として使い、コードは訳さずに書き直しています（違いは `CRITERIA.md` の「出典」に記載）。
論文本文はこのリポジトリに含めていません。作者は論文の本文（PDF）を読めていません。

## 4つの検証

| | 問い | コード | 基準と結果 |
|---|---|---|---|
| 検証1 | 論文のモデルで約4年周期が出るか・オコジョを抜くとどうなるか | `sim.py` | `CRITERIA.md` |
| 検証2 | 数値を動かしても4年が残るか（感度） | `check23.py` | `CRITERIA2.md` |
| 検証3 | 冬の増え方を年ごとに揺らしても4年が残るか | `check23.py` | `CRITERIA2.md` |
| 検証4 | 論文に無い「エサの上限」を足すとどうなるか | `check4.py` | `CRITERIA4.md` |

各 `CRITERIA*.md` の判定基準は、結果を見る前に書いて確定したものです。結果を見たあとに基準を動かしていません。
外れた見立ても、そのまま残しています。

### 結果の要点
- 検証1: 周期4年（250年で49回）、多い年と少ない年の差は約155倍。オコジョを抜くとレミングは増え続け、6年目に1haあたり100万匹を超えた（エサの上限が無いため）。
- 検証2: 14通りのうち10通りで4年のまま（71%・判定は保留）。
- 検証3: 冬の増え方を年ごとに1〜3割揺らすと、30本すべてでレミングが増え続けた（天敵だけでは抑えきれない）。
- 検証4: エサの上限を足すと、試した上限（1haあたり10〜100匹）のどれでも増え続ける本は0本になり、大発生の間隔の中央値は4年だった。
  ただし上限が大きく（100匹）揺らぎが強い（3割）と、間隔は3〜10年に散らばり、いちばん多いのは3年だった。
  上限ありでオコジョを抜くと、間隔の中央値は3年で、2〜6年にばらついた。
- 合わなかったこと: このモデルのレミングは1年で一気に減るが、本物は減るのに1〜2年かかっている
  （Barraquand et al., arXiv 2205.09441 p.10 も同じ点を指摘）。エサの上限を足してもここは変わらなかった。

論文の要旨はモデルが「4年周期を頑健に予測する」と書いていますが、検証3の結果はそれと食い違います。
論文本文を読めていないため、論文の「頑健」が何を動かした話なのかは確かめられていません。

## 動かし方

Python 3.13・numpy 2.4・scipy 1.17 で動作を確認しています。

```
pip install numpy scipy
python sim.py          # 検証1 → results.json
python check23.py      # 検証2・3 → results23.json
python check4.py       # 検証4 → results4.json（check23.py の関数を使う）
python export_daily.py --out trajectory_base.json   # 動画の3D用の日ごとのデータ
```

乱数のシードは固定しているので、同じ結果が出ます。全部で3分ほどです。

## `published/` について

動画を作ったときに出した結果です。上のコードを回すと、4ファイルとも1バイトも違わず同じものが出ます（確認済み）。

## 注意

- これはモデルです。本物のレミングと天敵の数を再現したものではありません。
- 動画の3D（ボクセル）の絵は、このデータから動物の数を計算して描いています（レミング1匹＝1haあたり1/20匹、天敵1頭＝1haあたり1/1000頭）。位置は見せ方です。3D の描画コードはこのリポジトリに含めていません。
